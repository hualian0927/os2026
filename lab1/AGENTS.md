# Lab1 working instructions

下列路径均相对于仓库根目录。

- 本仓库归属李华濂，远端为 `git@github.com:hualian0927/os2026.git`。
- 当前任务是完整完成实验一并提交代码、报告和证据，不再安排成员分工。
- 本次所有远程提交文件必须位于仓库的 `lab1/` 目录，后续实验使用各自独立目录。
- 每次 Git 提交标题必须以 `李华濂：` 开头，具体写明本次完成、实现、修复或配置的内容。不要使用没有内容的“更新”“修改”。
- 提交作者使用李华濂的身份。不添加 AI 署名或 AI 的 `Co-Authored-By`。
- 远端文档仅保留实验内容、环境说明和验证证据；本地过程性材料不纳入提交。
- 仅提交源码、必要文档和验证证据；不提交密钥、口令、令牌、构建产物、下载元数据或已废弃的分工计划。
- 修改前先阅读本实验的本地要求。实验一要求见 `lab1/内容/内容.txt`，本地准备材料如存在也可参考。
- 实验一自检：激活 Conda `os2026` 后进入 `lab1` 运行 `make grade`。这是本地自检，不能描述为课程官方评分。
- 有实质代码变更时运行相关验证；将用于报告的真实日志保存在 `lab1/docs/evidence/`，并在报告中区分源码推导、实际观察和未覆盖情况。
- 保留远端已有提交；未经明确要求不得强制推送或改写历史。
